# 기준판 (스타일 기준 도트)

AI 로 실험체 도트를 뽑을 때 **매번 참고 이미지로 같이 넣는** 그림이에요.
처음 2~3명(남 · 여 · 큰 체구 한 명씩)을 AI 로 뽑고 손으로 끝까지 다듬은 80×80 도트를 여기에 둬요.

- 파일 이름은 실험체 도트와 같게: `<ER번호>_<스킨>.png` (예: `1_00.png`)
- 기준판을 바꾸면 그 전에 만든 그림도 다시 맞춰요
- 자세한 방법: 도트 가이드 문서의 "통일된 그림 뽑는 법"
