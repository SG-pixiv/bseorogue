## 할 일 순서

1. 노트북 다운로드 폴더의 `drive-download-…` 폴더 접근 요청 → 실험체 폴더 목록 보기
   - 폴더 이름은 `번호. 영어이름` (팬키트 번호 ≠ ER 번호일 때가 있어요. 예: 팬키트 017 = 쇼이치 = ER 18). 영어 이름으로 맞춰요 (`er-data.ts` 의 `en`).
2. **빠진 실험체 확인해서 SG에게 알려 주기**: ER 91명 중 폴더가 없는 실험체, 폴더는 있는데 일러스트(Full · Half · Mini)가 없는 실험체, 음성이 없는 실험체
   - 첫 zip 기준으로는: 폴더 없음 24명 (재키, 하트, 리 다이린, 유키, 혜진, 시셀라, 루크, 바바라, 얀, 다니엘, 클로에, 띠아, 칼라, 이안, 데비&마를렌, 알론소, 레니, 츠바메, 케네스, 유스티나, 블레어, 미르카, 펜리르, 코렐라인)
3. **그림**: 실험체마다 필요한 PNG만 작업 공간으로 가져오기 (설정화 Concept Art · 배경화면 · 스킬 · 로비 영상은 빼요)
   - 가져올 것: `*_Full_NN.png`, `*_Half_NN.png`, `*_Mini_NN.png` (`NN` = ER 스킨 번호, 00 = 기본 모습)
   - `python3 scripts/fankit/build_art.py <가져온 팬키트 폴더>` 를 다시 돌리면 `assets/er/` 와 `art-manifest.ts` 가 새로 만들어져요.
   - 전투 그림은 전신 > 반신 순서, 아이콘은 얼굴(Mini) > 반신에서 얼굴 쪽. 스킨 진화한 모습은 그 스킨 번호 그림, 없으면 기본 모습.
4. **음성 (아직 도구 없음, 새로 만들기)**: 실험체 폴더의 `05. Voice Line/*.zip`
   - 언어: 한국어(KOR) > 영어(ENG) > 일본어(JPN) 순서로 하나만
   - 스킬 음성: 파일 이름에서 스킬 키 찾기. 이름이 실험체마다 달라요:
     - `Alex_skillQ1.wav`, `isol_skillQ_1_en.wav`, `silvia_skillE1_01.wav`, `Estelle_skillE1-solo-1_01.wav`, `magnus_skillPassive1.wav`
     - 엠마처럼 스킬 코드로 된 것: `Emma_PlaySkill1019200seq0_1_en.wav` → `10XX200` = Q, `300` = W, `400` = E, `500` = R (`XX` = ER 번호)
   - 등장 대사: `selected`, 없으면 `firstMove` (실험체가 나올 때 울음소리 대신)
   - 변환: ffmpeg 로 m4a (AAC, 모노, 64kbps 정도), 앞뒤 무음 자르기 → `assets/er/voice/<ER번호>_<q|w|e|r|select>.m4a` + 목록 파일
   - 게임: 실험체가 스킬(Q W E R = `skill-moves.ts` 의 순서)을 쓸 때 그 스킬 음성, 나올 때 등장 대사. 소리 크기는 게임 설정의 효과음 크기를 따라요.
   - 앞 작업에서 확인한 첫 zip 의 음성: 매그너스(일) 자히르(영) 이솔(영) 실비아(영) 엠마(영) 알렉스(한) 에스텔(일) 아이작(일) 샬럿(영) 크레이버(영)
5. 검사(`pnpm exec vitest run test/tests/bseorogue/`, `pnpm exec tsc --noEmit`) → 브라우저에서 고르기 화면 · 전투 화면 스크린샷 → 브랜치에 올리기 → SG 가 미리보기 확인 → main 에 합치기

## 지켜야 할 것

- SG 에게는 한국어로 설명해요.
- 비밀값(ER API 키, Supabase secret/service_role 키, 디스코드 토큰 등)은 코드 · 채팅에 절대 넣지 않아요. `er-key.txt` 는 커밋 금지.
- 큰 작업은 작업 브랜치에서. 시작할 때 예상 시간을 말하고, 단계가 끝날 때마다 바로 알리고 스크린샷을 보내요.
- 커밋 메시지 끝에는 그 작업의 서명 줄(Co-Authored-By · Claude-Session)을 붙여요.
- 팬키트 그림 · 소리는 `assets/er/` 에만 두고 (REUSE.toml 에서 님블뉴런 라이선스로 표시돼 있어요), 출처는 `assets/er/README.md`.
