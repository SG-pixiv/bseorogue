# 블서로그 기획 (정해진 것)

> 마지막 정리: 2026-11-02 · SG 답변 기준. 바뀌면 이 문서부터 고쳐요.

## 한 줄 소개
포켓로그(PokeRogue) 배틀 엔진에 이터널 리턴 실험체를 넣은 로그라이트 웹게임. 무명섬 사이트 유입용 "큐 잡는 동안 하는 게임".

| 항목 | 결정 |
|---|---|

| 저장 | 로그인 없음 · 브라우저 저장 + 저장 파일 내보내기/가져오기 |

| 파티 | 최대 3명 (나중에 바꿀 수 있게) |
| 한 판 | 클래식 50웨이브 (나중에 늘림) · 10웨이브마다 보스 |

| 영입 | **가챠만** (판 중 포획 없음). 포켓로그 알 가챠 → ER식 보급 상자 / 보급 요청권 |
| 돈 | 크레딧 · 포켓로그처럼 보상 고르기 + 상점 구매 |
| 패배 | 전멸하면 게임 오버 · 부활 아이템 있음 |

## 배틀 규칙
- **상성(타입) 6종:** 탱커 · 브루저 · 암살자 · 평원딜 · 스증딜러 · 서포터
- **스탯 6개:** 체력 · 공격력 · 방어력 · 스킬 증폭 · 스킬 저항 · 속도 (포켓로그 HP · 공격 · 방어 · 특공 · 특방 · 스피드 자리)
- **기술:** 실험체 고유 Q/W/E/R (효과는 나중에 다듬기). 사용 횟수(PP) 그대로
- **특성:** 고유 패시브 = 특성 자리, ER 특성 = 패시브 자리(해금)
- **상태이상 이름:** 독→중독 · 맹독→출혈 · 화상→화상 · 마비→둔화 · 수면→기절 · 얼음→속박
- 능력치 단계(+1~+6) 그대로 · 날씨는 처음엔 끔 · 낮/밤은 배경 연출만 · 금지구역은 나중에
- 난이도 목표: 처음 하는 사람의 50웨이브 클리어율 10~20%

## 콘텐츠
### 시작 실험체 (모두 1코스트)
| 역할군 | 실험체 | 무기 |
|---|---|---|
| 탱커 | 일레븐 | 망치 |
| 브루저 | 유키 | 양손검 |
| 암살자 | 쇼이치 | 단검 |
| 평원딜 | 나딘 | 석궁 |
| 스증딜러 | 혜진 | 암기 |
| 서포터 | 레니 | 권총 |

- 종족값 (`src/data/bseorogue/stats.ts`, 실험체별 숫자는 `roster.ts`): 포켓로그 진화 라인을 참고
  - 코스트가 같으면 합이 같음. 1코스트 = 기본 320 → 스킨 진화 1 410 → 스킨 진화 2 500 (이상해씨 318 → 405 → 525 정도)
  - 2~4코스트는 다 큰 모습 520 · 540 · 560 (초안), 5코스트 이상은 처음부터 580~600 (포켓로그 전설처럼)
  - 실험체마다 다른 건 "어디에 중점을 두는지": 일레븐 체력 · 유키 공격력+방어력 · 쇼이치 속도 · 나딘 공격력 · 혜진 스킬 증폭 · 레니 스킬 저항
  - 공격력은 물리 스킬, 스킬 증폭은 특수 스킬에 쓰여서 스킬 종류도 맞춤 (평원딜 · 브루저 · 암살자 · 탱커 = 물리, 스증딜러 · 서포터 = 특수)
  - 동물: 모양은 ER 몬스터 스탯, 합은 웨이브 단계 (닭 220 · 박쥐 250 · 멧돼지 320 · 들개 360 · 늑대 430 · 곰 500)
  - 보스: 알파 420 → 오메가 480 → 감마 540 → 위클라인 600 → 루미 680 (뮤츠급, 체력 칸 하나 더)
- **스킨 진화 (임시 순서, 완성 뒤 SG가 정함):** 기본 모습 → 스킨 진화 1 (Lv12) → 스킨 진화 2 (Lv24)
  - 지금은 ER 스킨 목록의 1번 · 2번 스킨을 씀. `src/data/bseorogue/skin-evolution.ts` 표만 고치면 스킨 · 레벨 · 역할군 변화가 바뀜
  - 레벨 상한(포켓로그 규칙): 1~10웨이브 Lv10 · 11~20 Lv16 · 21~30 Lv24 · 31~40 Lv32 · 41~50 Lv38 → 스킨 진화 1은 12~15웨이브쯤, 2는 28~31웨이브쯤
- **ER 실험체 전부(91명)가 게임 안에 있음.** 고를 수 있는 건 `roster.ts` 의 `BSEO_PLAYABLE` 에 적은 실험체(지금 6명)이고, 나머지는 KEL 팀 같은 적으로만 나옴
  - 역할군은 ER 실험체 분류(charArcheType1)를 따름: Tanker 탱커 · Warrior 브루저 · Assassin 암살자 · Marksman 평원딜 · Mage 스증딜러 · Supporter 서포터
  - 따로 정하지 않은 실험체 종족값은 역할군 기본 모양 (`stats.ts` 의 `ROLE_SHAPE`), 1코스트
- 고유 패시브 · Q/W/E/R: 이름은 ER 데이터, 효과는 포켓로그 기술을 빌려 씀 (`skill-moves.ts`, 시작 6명은 직접 고름 · 나머지는 역할군에 맞춰 자동으로 고른 초안). 효과는 나중에 SG가 줌
- 첫 공개 목표: 실험체 30명 (`BSEO_PLAYABLE` 에 추가)

### 적
- **야생:** 동물(닭 · 박쥐 · 멧돼지 · 들개 · 늑대 · 곰 + 변이체)은 영입 불가 적. 일러스트 + 옛날 사기 실험체 기반 적은 SG가 나중에 정리
- **적 팀(트레이너 자리):** KEL 16팀. 5 · 15 · 25 · 35 · 45웨이브에 한 팀씩 (판마다 순서가 다르고 한 판에 같은 팀은 안 나옴). 팀마다 실험체 3명은 SG가 무명섬 관리 화면에서 정함. 아직 안 정한 팀 · 무명섬에 연결이 안 될 때는 무작위 실험체. 팀 로고가 있으면 팀 그림에 씀
- **라이벌:** 나중에
- **보스 (강해지는 순서):** 10 알파 → 20 오메가 → 30 감마 → 40 위클라인 → 50 최종 보스 **안내 로봇 루미 (경계 모드)** · 일러스트는 AI 스트리머 루미

### 아이템 (포켓로그 효과 그대로, 이름만 ER)
- 보상에서 빠진 것: 기술머신 · 테라스탈 · 메가 · 다이맥스 · 합체(DNA) · 특성 부적 · 포획 부적 · 더블배틀 향수 · 진화 돌 · 폼 체인지 아이템
- 나무열매 → ER 음식 이름 (사과 · 황금사과 · 수박 · 초콜릿 · 감자 · 양송이 버섯 · 호박 고구마 · 후라이드 치킨 · 트러플 · 꿀고구마 · 루텔라)

## 랭킹 · 무명섬 연결
- 닉네임만 적고 올리기 (로그인 없음) · 클래식 기준
- 순위: 최고 웨이브 → 짧은 시간 → 먼저 올린 순 · 닉네임마다 최고 기록 1개
- 이번 주(월요일 0시 초기화) + 역대
- 닉네임 2~12자 (한글 · 영문 · 숫자 · _), 금지어, 무명섬 선수 이름 · 게임 닉네임과 같으면 막음
- 하루 올리기: 닉네임당 5번, 같은 인터넷 연결당 20번
- 자동 거절: 웨이브당 15초보다 빠름 · 50웨이브 초과 · 버전 다름 · 없는 실험체
- 새 1등은 바로 보이고, 이상하면 관리자가 숨김
- 무명섬 화면: **기존 디자인은 그대로**. 공개 전에는 관리자 화면에만 보이고, 공개하면 메뉴 끝에 "블서로그" 한 칸만 생김. 메인 대시보드는 무명섬 데이터만. 블서로그 랭킹 · 업데이트 소식 · 피드백은 별도 페이지(/rogue)
- 피드백 · 업데이트 소식은 모두 웹(무명섬 블서로그 페이지)에서
- 무명섬 관리자 화면에 블서로그 관리 (공개 스위치, 검사 기준, KEL 팀 실험체 · 로고, 기록 숨기기, 소식, 피드백)
